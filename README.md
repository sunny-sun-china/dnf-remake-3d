# 赫顿玛尔 · 三维街区漫游

一个可以用键盘操控的 Three.js 街区。以早期国服《地下城与勇士》的赫顿玛尔为参考，鬼剑士可以走过月光酒馆、凯丽的强化机和杂货摊，靠近居民时能听到中文招呼。

## 离线游玩

将仓库根目录的 `index.html` 下载到电脑，用支持 WebGL 2 的桌面浏览器打开。模型、贴图、音乐和语音都嵌入了这一个文件。第一次点击画面或按移动键即可启用声音。

| 操作 | 控制 |
| --- | --- |
| 移动 | WASD 或方向键 |
| 跑动 | 按住 Shift 移动 |
| 环视与缩放 | 拖动鼠标、滚动滚轮 |
| 镜头回正 | R |
| 街区地图、素材权利说明 | M 或右上角地图按钮 |

## 从源码构建

在项目目录执行以下命令。项目已在 Node.js 22 下验证，首次安装依赖需要网络。

```sh
npm ci
node --test
npm run build
```

构建结果为根目录的 `index.html`。修改源码或运行素材后，重新构建并一并提交这个文件，方便其他人直接打开游玩。
